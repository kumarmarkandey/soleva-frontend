# SOLEVA — Premium Sneaker Store

A responsive, interactive sneaker e-commerce frontend built with React, Vite and Three.js.

## Features

- Responsive desktop/tablet/mobile layout
- Interactive 3D sneaker built with Three.js
- Scroll-reactive hero sneaker movement
- Product search
- Category filtering
- Sorting
- Wishlist
- Functional shopping cart
- Quantity controls
- Responsive mobile navigation
- Reduced-motion accessibility support
- Portfolio-ready visual system

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Render

Create a **Static Site** connected to this repository.

- Build Command: `npm install && npm run build`
- Publish Directory: `dist`

This project is frontend-only for now. The cart/wishlist state is intentionally client-side; a backend, authentication, payments and persistent database can be connected next.
